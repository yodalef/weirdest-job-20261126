A Python program that writes one job title — the Executive Vice President of Turning It Off and On Again, the most senior role in any company, held by whoever the machine respects enough to start working for — to /output/entry.txt. The title is UTF-8 text of 55 characters, within the bounty's 60-character limit. Deterministic and offline: no network use.

## Run it

```sh
python3 main.py
```

Writes the title to /output/entry.txt (or ./output/entry.txt when /output is not writable).
